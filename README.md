# Kamizeta

Loja em HTML, CSS e JavaScript integrada ao Supabase. Base visual e estrutura inicial do banco preparadas; Google Drive, Uber Entregas e InfinitePay dependem de credenciais, permissões e testes reais.

## Publicação
Conecte o repositório à Vercel como site estático, diretório raiz `./`, sem build command. Adicione a logomarca real como `kamizeta.png`. Nunca publique segredos. Configure credenciais externas exclusivamente nos secrets das Edge Functions.

## Status
Checkout, cotação real da Uber, webhook InfinitePay e galeria Google Drive ainda não devem ser considerados prontos até configuração e validação real.
